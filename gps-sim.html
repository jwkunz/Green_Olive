3. Simulated IQ recording (.wav)
Real GPS C/A signal power sits well below the noise floor — this sim keeps that ratio, so satellites won't be visible in a raw time-domain plot without correlation, same as a real receiver.
Signal chain: ideal sum of satellites + thermal noise → front-end bandwidth filter → AGC (regulates on total power, same as real hardware — it can't "see" the buried GPS signal specifically) → ADC quantization. Quantized output is still stored in a standard 16-bit WAV container for compatibility; only a handful of amplitude levels are actually used.
